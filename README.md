# MaxMail

E-Mail client project for BlackBerry OS 7. MaxMail consists of a client application (J2ME) and a private Node.js backend server. Only paired devices can access the server.

## Features and Optimizations
- Device pairing authentication using SHA-256 (no shared secrets in source code)
- IMAP connection pooling and 30-second response caching on the server
- Gzip response compression
- Minimized JSON payloads with shortened keys
- Optimized memory usage and garbage collection tuning for the J2ME client

## Prerequisites

### Backend Server
- Node.js (v14 or higher recommended)

### J2ME Client Compilation
- NetBeans IDE 7.3.1
- Sun Java Wireless Toolkit 2.5.2
- Java JDK 8 Update 202

## Server Setup

1. Navigate to the server folder and install dependencies:
   ```bash
   cd MaxMailServer
   npm install
   ```

2. Copy `.env.example` to `.env` and configure your IMAP/SMTP credentials:
   ```bash
   cp .env.example .env
   ```

3. Start the server in pairing mode for the first-time setup:
   - Linux/macOS:
     ```bash
     PAIR_MODE=true node server.js
     ```
   - Windows PowerShell:
     ```powershell
     $env:PAIR_MODE="true"; node server.js
     ```
   - Note the 6-digit PIN printed to the console.

## Client Setup and Pairing

1. In the J2ME client source code, set the server URL in `Midlet.java`:
   ```java
   private String serverUrl = "http://YOUR_SERVER_IP:3000";
   ```

2. Compile the client and install the resulting COD/JAD files onto the BlackBerry device.

3. Launch MaxMail on the device.

4. Open Settings in the app, enter the server URL, enter the 6-digit PIN generated by the server, and press Pair.

5. Once paired, the server console will confirm the pairing. Restart the server in normal mode (without `PAIR_MODE=true`):
   ```bash
   node server.js
   ```

6. The device will automatically authenticate and log in using the established pairing token.

## Unpairing / Resetting Devices

- Paired devices are stored in `paired_devices.json` in the `MaxMailServer` directory.
- To unpair all devices, delete `paired_devices.json` and restart the server.

## Troubleshooting

### Authentication / Login Failures
- **Time Synchronization**: The authentication protocol uses minute-based SHA-256 OTP hashes. Ensure that both the Node.js server system time and the BlackBerry device time are synchronized (accurate within a ±1 minute threshold). If the clocks diverge, authentication will fail with a 401 response.
- **Connection Issues**: Verify the client's `serverUrl` matches the server's IP and port, and that there are no firewalls blocking port 3000.
